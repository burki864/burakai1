BurakAI APK Dosyası
====================
Sunucudan doğrudan kendi derlediğiniz APK dosyasını sunmak için:
1. Bu klasörün içine "BurakAI.apk" adıyla dosyanızı yükleyin veya sürükleyip bırakın (`/public/BurakAI.apk`).
2. Kullanıcılar İndir butonuna bastığında sunucunuz doğrudan bu dosyayı indirecektir.
3. Dosya burada bulunmadığında sistem otomatik olarak GitHub Releases adresindeki en güncel v2.1 APK sürümüne yönlendirir.
